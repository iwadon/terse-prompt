## 既知の制限事項

### 実装上の制限

1. **複雑なグラフィームクラスタ** — 絵文字の削除が不完全になる可能性
2. **シングルスレッド専用** — マルチスレッド対応は未実装
3. **端末サイズ変更** — 動的リサイズ未テスト
4. **Windowsコンソールのコードページ** — terse-promptは戻り値としてUTF-8文字列を返すが、コンソール出力コードページの管理は行わない。Windowsで非ASCII文字（日本語など）を扱う場合、アプリケーション側で `SetConsoleOutputCP(CP_UTF8)` / `SetConsoleCP(CP_UTF8)` を呼び出す必要がある。`examples/example_console.h` がこの定型処理を提供している

### 設計上の制限

1. **キーバインド**: Emacs風のみ（Viモード未実装）
2. **構文ハイライト**: 未実装
3. **Undo/Redo**: 未実装
4. **コピー&ペースト**: OS機能のみ（キルリング未実装）
